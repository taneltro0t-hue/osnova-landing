# ОСНОВА — рекламная посадочная (v2.1)

Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, `config.js`, `privacy.html`, `consent.html`, `assets/`. Открывается с любого хостинга. На `localhost` и `*.github.io` аналитика и отправка формы выключены.

## Идея страницы

Конкуренты в Ставрополе продают обещания без фамилий и без цен. Эта страница продаёт проверяемые факты: собственный загородный центр с 2014 года, 847+ прошедших программу, команда из пяти специалистов с именами и стажем, лицензированный медицинский партнёр «Амадея» в той же связке, условия дома (комнаты на 2–3 человека, 4-разовое питание, бассейн, баня), цена от 2 000 ₽ в сутки с первичной консультацией бесплатно.

Порядок: первый экран по сценарию → «Почему выбирают» (4 факта) → выбор ситуации (семья / алкоголь / наркотики / сам) → условия с реальными фото → команда → медицинский партнёр → программа и цена → план после звонка → FAQ → форма.

Входы для рекламы: `?case=family|alcohol|drugs|self`, либо пути `/semya`, `/alkogolizm`, `/narkomaniya`, `/sam` (если хостинг отдаёт `index.html` на эти пути). Якоря для быстрых ссылок Директа: `#proof`, `#situations`, `#conditions`, `#team`, `#partner`, `#program`, `#after-call`, `#faq`, `#callback`.

## Откуда взяты факты

Всё со страниц основа26.рф и amadeya26.ru на 4 сентября 2026: год основания, 847+, 20 городов и выезд от 40 минут, состав и стаж команды, 27 документов о квалификации, условия проживания, этапы и сроки программы, цена от 2 000 ₽ в сутки, лицензия и адрес партнёра. Для модерации Директа по медицинской тематике держите под рукой копию лицензии «Амадеи» с приложениями и подтверждение цифр.

## Что заполнить до публикации (на странице выделено янтарным)

| Место | Что нужно |
|---|---|
| Подвал, `privacy.html`, `consent.html` | юрлицо, ИНН, ОГРН, e-mail оператора данных |
| Подвал | номер дома на ул. Доваторцев |
| `config.js` | `formEndpoint` — URL приёма заявки |
| Команда | фотографии специалистов вместо монограмм, при наличии согласия |

## Аналитика

Счётчик Метрики `103396251` задан в `config.js`. Создать цели типа «JavaScript-событие»: `form_success` (основная), `phone_click`, `form_start`, `scenario_select`, `call_prompt_open`, `faq_open`, `callback_scroll`, `form_error`. В Метрику уходит параметр визита `case`. Форма отправляет `phone, contact_time, case, utm_*, yclid, landing_url, referrer`.

## Локальный просмотр

```bash
python3 -m http.server 8080
```

Открыть <http://localhost:8080/?case=drugs>.
