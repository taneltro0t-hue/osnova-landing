# ОСНОВА — рекламная посадочная (v2)

Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, `config.js`, `privacy.html`, `consent.html`, `assets/`. Открывается с любого хостинга. На `localhost` и `*.github.io` аналитика и отправка формы выключены.

## Идея страницы

Рынок Ставрополя продаёт гарантии («гарантия избавления», «95%», «за 21 день», «повторный курс бесплатно») и срочность (24/7, выезд в день обращения). Эта страница делает противоположное и говорит об этом вслух: блок «Что обещают на этом рынке» перечёркивает четыре типовых обещания и отвечает на каждое, а вместо процентов показывает день центра по часам с реальными фотографиями. Дальше: четыре сценария (семья / алкоголь / наркотики / сам), план после звонка, честная граница «медицина у партнёра — реабилитация у ОСНОВЫ», состав программы и цена без звёздочек, FAQ, форма.

Входы для рекламы: `?case=family|alcohol|drugs|self`, либо пути `/semya`, `/alkogolizm`, `/narkomaniya`, `/sam` (если хостинг отдаёт `index.html` на эти пути). Якоря для быстрых ссылок Директа: `#promises`, `#situations`, `#day`, `#after-call`, `#stages`, `#terms`, `#faq`, `#callback`.

## Что заполнить до публикации (на странице выделено янтарным)

| Место | Что нужно | Источник |
|---|---|---|
| Подвал, `privacy.html`, `consent.html` | юрлицо, ИНН, ОГРН, адрес, e-mail оператора данных | владелец + юрист |
| Подвал | адрес центра в Ставрополе | владелец |
| «После звонка» | реальное время ответа (SLA) | отдел приёма |
| «Что входит и сколько стоит» | стоимость, срок программы, состав | владелец |
| «Медицина и реабилитация», подвал | номер лицензии ООО «Амадея» и адрес оказания услуг **или** убрать медицинские формулировки | владелец + юрист |
| «Один день в центре» | сверить распорядок с реальным (сейчас указан типовой) | руководитель программы |
| `config.js` | `formEndpoint` — URL приёма заявки | разработчик |

## Аналитика

Счётчик Метрики `103396251` задан в `config.js`. Создать цели типа «JavaScript-событие»: `form_success` (основная), `phone_click`, `form_start`, `scenario_select`, `call_prompt_open`, `faq_open`, `callback_scroll`, `form_error`. В Метрику уходит параметр визита `case`. Форма отправляет `phone, contact_time, case, utm_*, yclid, landing_url, referrer`.

## Локальный просмотр

```bash
python3 -m http.server 8080
```

Открыть <http://localhost:8080/?case=drugs>.

## Что нельзя добавлять без документов

Проценты, гарантии, сроки «вылечим за N дней», цены и адреса без подтверждения, фото лиц без разрешения, фасад здания (по решению владельца не публикуется).
